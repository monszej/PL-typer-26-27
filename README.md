# Premier League Typer

1. Wstaw klucz API do config.py
2. pip install -r requirements.txt
3. streamlit run app.py

Funkcje:
- pobieranie terminarza Premier League
- zapisywanie typow
- ranking
- punktacja 3/1/0

Do rozbudowy: hasla, rejestracja, automatyczna blokada po kickoff (obecnie łatwa do dodania przy sprawdzeniu utcDate).
